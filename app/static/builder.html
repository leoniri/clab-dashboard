Addressing

Each link takes the next subnet from the pool; each node takes the next loopback. Both ends of every link are addressed automatically.

Routing

How roles and services work

Roles come from each node (click it): P and PE form the core IGP, RR reflects iBGP, CE sits in its own AS. PE–CE links run eBGP — inside the CE's VRF when L3VPN is on. Links between different ASes run eBGP; CEs advertise their loopback. Prefix-SID index = node number.
